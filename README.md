# eng_game
根據這張單字卡的全部單字內容，設計一個給高中生學習英文的遊戲網站。
檔案說明：
(1)圖片「eng_list.png」是要用來練習的全部單字。
遊戲設計要求：
(1)遊戲的主要對象是高中生一年級學生。
(2)遊戲的學習目標是要讓學生容易記憶單字與句子的應用。 
(3)遊戲設計應具備教學、練習、測驗、記錄的概念。 
(4)遊戲能學習全部單字及單字應用的句子。
(5)遊戲中出現的單字和句子要能發音。 
(6)遊戲畫面模仿流行的皮克敏畫面及動畫設計。
(7)遊戲中設計多項關卡與情境設定。 
(8)遊戲要記錄學生的學習歷程，並以儀表板顯示學生的學習成效。
產出：
(1)設計並產出這個視覺化互動式的單頁 HTML 遊戲網頁。
(2)請為我生成這款遊戲的腳本，並提供 Word 文件。
